## Summary

AI makes code cheaper, so more custom software will be built—but checking that it works becomes harder.
This may disrupt some software businesses and change how teams hire and work.
Software development will remain important, and problem-solving skills will matter more than any one technology.

## Highlights

- I’d encourage teams to track validation debt as seriously as technical debt. Cheap code speeds up exploration, but only if we check ideas against real users and real needs.
